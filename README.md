# FP-Agent

An autonomous agent framework for FP (Financial Planning) workflows.

## Overview

FP-Agent is a lightweight, composable agent runtime designed to automate
financial-planning tasks: data ingestion, analysis, plan generation, and
reporting.

## Features

- **Modular** — pluggable tools, memory, and model providers.
- **Deterministic** — every run is reproducible given the same inputs.
- **Observable** — structured logs and traces for every decision step.

## Getting Started

```bash
git clone https://github.com/pingfeng1989/fp-agent.git
cd fp-agent
```
